# Pemetaan buku ke disertasi

Daftar pustaka buku digabungkan dengan daftar pustaka disertasi. Semua tabel sumber diberi caption dan label agar masuk Daftar Tabel. Gambar mempertahankan caption dan label sumber. SVG asli tetap disimpan; naskah memakai PNG 300 DPI agar render PDF tidak memerlukan `rsvg-convert`.

## Pemeriksaan

- 112 bagian isi sumber terpetakan; judul 14 bab sumber menjadi pengelompokan materi, tanpa kehilangan isi.
- 32 gambar sumber tersedia; 88 berkas aset tersalin identik.
- 78 tabel sumber diberi caption dan label; ditambahkan satu tabel keterlacakan PP dan satu tabel dataset harian (80 tabel keseluruhan).
- Tidak ada label gambar/tabel duplikat, jalur gambar hilang, atau sitasi tanpa entri bibliografi.
- Simulasi berhasil dijalankan ulang dan menghasilkan angka sesuai sumber. Grafik sumber tetap digunakan; Matplotlib tidak tersedia pada Python pemeriksaan.
- Pandoc berhasil membaca naskah dan memproses sitasi tanpa peringatan.
- `git diff --check` lulus.
- Render PDF `quarto render` berhasil setelah referensi gambar diganti ke PNG 300 DPI. PDF akhir berjumlah 131 halaman dan memuat 32 gambar materi serta satu gambar sampul. Halaman diagram, tabel hasil, dan dataset diperiksa secara visual.
- PDF hasil tersedia di `_book/dokumen-itb.pdf` dan disalin ke `dokumen-itb.pdf`.

## Render

Setelah lingkungan Quarto/LaTeX siap, dari folder `disertasi` jalankan `quarto render`. Format PDF ITB dan struktur enam bab/empat lampiran dipertahankan.

## Perbaikan render PDF

Penyebab error adalah konversi SVG ke PDF yang memerlukan `rsvg-convert`. Seluruh 32 gambar yang dirujuk kini memiliki PNG 300 DPI yang langsung didukung LaTeX. Spasi label Mermaid dipertahankan saat konversi. `resources/pdf-layout.tex` membatasi gambar tinggi agar menyisakan ruang caption; header dataset dipadatkan dengan notasi yang dijelaskan di teks.

PNG sudah tersedia sehingga `quarto render` tidak memerlukan instalasi konverter gambar. Jika SVG diubah, jalankan `node scripts/prepare-pdf-images.mjs` dari folder `disertasi`; skrip memerlukan paket Node `sharp` (`npm install --no-save sharp`). Lalu jalankan `quarto render`.
